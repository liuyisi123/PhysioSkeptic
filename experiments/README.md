# Experiment resources

Aggregate study results are not currently distributed in this directory.
For a new evaluation, retain the input selection, patient-level partition,
configuration, model identifier, role templates and predictions together with
the reported metrics. Separate run-specific results from synthetic demo output.

The [reproducibility guide](../docs/reproducibility.md) describes the current
software coverage. The [usage guide](../docs/usage.md#jsonl-batch-processing)
shows how the mock batch script reads and writes JSONL; that script is not a
benchmark reproduction command.

Only share derived results when the source-data terms permit redistribution,
and keep patient identifiers and credentials outside the public repository.
