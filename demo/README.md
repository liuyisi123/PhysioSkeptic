# Browser demonstration

Open [index.html](index.html) locally in a browser. The page is self-contained:
no server, package installation or API key is required.

Adjust signal quality, initial confidence and cross-modal conflict to inspect
Fast, Standard and Deep route selection, challenge allocation and an
illustrative Patch Report trace. The display uses synthetic examples and
deterministic interactions; it does not run the encoder or call a language model.

For the executable synthetic signal pipeline, run the following from the
repository root:

```bash
python scripts/run_demo.py
```

Return to the [project overview](../README.md#demonstrations) or read the
[usage guide](../docs/usage.md) for the Python interface.
